# 최저가 캘린더와 가격 추이

- **캘린더**: 3개월 내 실제 검증된 왕복 직항의 출발일별 최저가를 표시합니다. 목적지, 인천·김포 출발 공항, 3~6일 여행 기간 필터를 적용하며 클릭하면 여행 일정과 Google Flights 검색 링크로 연결됩니다. 공란은 **미조회/미확인**이지 매진이 아닙니다.
- **가격 이력**: worker/update-price-history.mjs가 매일 항공권 스냅샷에서 검증된 ICN/GMP, 도착 공항, 도시, 여행 기간별 **관측 최저가**만 dist/price-history.json에 누적합니다. 원본 항공권 전체를 매일 복제하지 않으며 기록은 최대 120일 보존합니다.
- **특가 점수**: 7일·30일 구간에서 이전에 관측된 서로 다른 날짜가 **최소 3일**일 때만 점수를 산출합니다. 기준 가격은 이전 날짜의 일별 최저가 중앙값입니다. 계산식은 clamp(round(50 + 2.2 × (기준가격 - 현재가격) / 기준가격 × 100), 0, 100)입니다. 기준 가격과 유효 관측일 수를 화면에서 공개합니다.
- **비교 기준**: 가격 추이는 *해당 날짜에 검색된 서로 다른 향후 여행 출발일의 관측 최저가*입니다. 동일한 좌석·편명·출발일 항공권 자체의 가격 변동이 아닙니다. 미검증 여행사 출발 가능 기간은 달력에 넣지 않습니다.
- **실행**: 정기 전체 검색 성공 시 GitHub Actions가 dist/price-history.json을 갱신하고 커밋합니다. 초기 실행은 Seed verified flight price history 액션으로 수집된 현재 스냅샷의 기록 한 건을 만들 수 있습니다.
- **검증**: npm run test:unit, node --check dist/fare-insights.js.

## 이전 기록 처리

실제 관측을 시작하기 전 과거 7·30일 가격은 만들어 넣지 않습니다. 첫 실행 시 기록 1일만 있으므로 추이 그래프는 점 하나이고 특가 점수는 미산출로 표시됩니다. 관측 데이터가 쌓이면 점수가 자동으로 표시됩니다.
